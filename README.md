# Python Algorithms

Clean Python solutions to common algorithm problems, with docstrings, examples, and time/space complexity analysis.

## Solutions

| Problem | Approach | Time | Space |
|--------|----------|------|-------|
| [Two Sum](two_sum.py) | HashMap | O(n) | O(n) |
| [Valid Parentheses](valid_parentheses.py) | Stack | O(n) | O(n) |
| [Group Anagrams](group_anagrams.py) | HashMap + Sort | O(n k log k) | O(n) |
| [Longest Substring Without Repeating Characters](longest_substring.py) | Sliding Window | O(n) | O(n) |
| [Best Time to Buy and Sell Stock](best_time_to_buy_sell_stock.py) | Greedy | O(n) | O(1) |
| [Climbing Stairs](climbing_stairs.py) | Dynamic Programming | O(n) | O(1) |

## Running the Solutions

```bash
python two_sum.py
python valid_parentheses.py
python group_anagrams.py
python longest_substring.py
python best_time_to_buy_sell_stock.py
python climbing_stairs.py
```

- Hash Maps and Dictionary lookups
